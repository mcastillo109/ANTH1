# Antibiotic Resistance Virtual Lab

Static, GitHub Pages-ready virtual replacement for the antibiotic resistance dice-and-disk activity in the supplied worksheet.

## Publish on GitHub Pages

The site files live in `dist/`. Either configure GitHub Pages to deploy from the `dist` folder, or copy the contents of `dist/` to the repository root before publishing.

The activity is self-contained and uses no build step. Students roll a virtual number cube for each of eight treatment days and watch blue, yellow, and red bacteria change in a virtual petri dish according to the worksheet rules.
