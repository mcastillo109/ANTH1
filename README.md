# Antibiotic Resistance Virtual Lab

Based on https://ciblearning.org/wp-content/uploads/2017/04/04AntibioticResistanceP15_22.pdf
Coded using ChatGPT
Webapp replaces need for physical materials

## Publish on GitHub Pages

Students roll a virtual number cube for each of eight treatment days and watch blue, yellow, and red bacteria change in a virtual petri dish according to the worksheet rules.
